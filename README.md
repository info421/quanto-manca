# Quanto manca

Widget Android che mostra i prossimi appuntamenti del calendario in ordine di quanto manca, con colore per urgenza e pulsante "+" per inserirne di nuovi.

## Scaricare l'app

Dal telefono apri **Releases → latest** e scarica `QuantoManca.apk`, poi installalo (consenti l'installazione da questa fonte quando Android lo chiede).

Ogni modifica caricata sul ramo `main` ricompila l'APK in automatico (GitHub Actions).

## Colori

- rosso: entro 24 ore
- arancio: entro 3 giorni
- giallo: entro una settimana
- verde: entro un mese
- blu: più avanti
